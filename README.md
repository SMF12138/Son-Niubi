# Son Niubi — 人民币兑卢布方向预测仪表盘

本地网页仪表盘：基于俄罗斯央行（CBR）官方日牌价 + 莫斯科交易所（MOEX）在岸成交价，预测 **1 人民币 = ? 卢布** 汇率的未来涨跌方向（7 / 30 / 60 / 90 交易日）。

页面如实展示真实回测命中率，并与基线并列对照，不虚标。**本项目不构成投资建议。**

---

## 数据源（全部免密钥）

| 源 | 用途 | 说明 |
| --- | --- | --- |
| **CBR** `XML_dynamic` | 官方日牌价（主） | 币种 CNY（`R01375`）、USD（`R01235`，衍生特征）。首抓自 2010-01-01，之后增量。 |
| **CBR** `KeyRate` HTML | 关键利率 | 在线抓取 3255 行（2013-09→今），失败回退 38 行硬编码（只取 ≤ 今天的条目，避免未来数据）。 |
| **MOEX ISS** | 在岸成交价（核心信号） | CNYRUB_TOM 日线，2022-06 起。**领先 CBR 次日牌价**，是方向预测的主信号。 |
| **er-api** | 兜底 | CBR 不可用时补最新一日，标 `erapi` 来源。 |
| Brent 油价 | 特征 | GitHub datasets/oil-prices（主）+ Yahoo Finance BZ=F（备用）。 |
| 新闻情绪 | 特征 | Google News RSS 关键词情绪打分（扩展词频版，~100 词，分辨率有限）。 |

## 7 日方向预测能力（真实回测 · MoexDirectionPredictor）

严格 walk-forward，滚动标准化只用 ≤t 数据，无前视。最新回测（`data/direction_result.json`，as_of 2026-09-11，4124 行；有效窗口 3116–3199 个）：

| Horizon | 全样本¹ | 高置信(>65%, 样本外)² | **MOEX 期**³ | 多数类基线 |
| --- | --- | --- | --- | --- |
| 7 日 | 58.0% | **70.0%**（n=424） | **67.4%**（n=982） | 51.8% |

> 30/60/90 日**不再使用本模型**（旧口径长周期超额仅 +1~3 个点且不稳定），改用下文"长周期 70% 门槛模型"。

> ¹ **全样本**：2013-09（关键利率数据起点）至今。2010–2013 段因 key_rate 特征无法无前视填充（旧实现用 `bfill` 把未来利率提前，属前视偏差，已修），已从有效样本排除。
> ² **高置信为扩展窗样本外（OOS）数字**：回测中给 t 时刻的预测定置信时，只允许使用结果已实现（j+N≤t）的历史窗口统计命中率；桶内不足 20 样本回退内置默认表。旧实现用全样本（含被评估窗口）校准再回头选档，该数字偏乐观，已弃用。门槛 0.65（旧 0.60 对 MOEX 信号几乎无筛选力）。
> ³ **MOEX 期**：2022-06 起有 MOEX 在岸成交的子集；7 日 MOEX 期高置信（OOS）命中率 70.0%（n=335）。

**按信号强度分档（生产校准表，与 `calibration.json` 一致，2026-09-11）：**

口径为 **P(命中 | |z|>阈值)**，阈值**累积**（z>1.0 桶包含 z>1.5 的样本，非互斥分箱）。这是**生产预测**用的全样本校准——实盘时点全部历史结果均已实现，不存在前视；回测里的高置信命中率则使用上面的样本外扩展窗版本。

| | z>1.5（极强）| z>1.0 | z>0.5 | z≤0.5（弱）|
|---|---|---|---|---|
| N=7 | **79.2%** | 69.6% | 69.6% | 61.6% |

> **z>1.0 与 z>0.5 同值不是笔误**：N=7 实测 z>1.0 档曾为 64.5%(n=124) 反而低于 z>0.5 档 72.1%(n=269)，两比例检验 |z|=1.49 → **统计上不可区分**。此时按**样本量加权池化**（合并 n=393 → 69.6%），双向收敛且方差更小（N=30 同理 → 65.0%）。
> 若某档差异**确实显著**（|z|≥1.96），代码会**如实保留非单调、不做池化** —— 宁可显示反直觉，也不发布数据不支持的数字。N=60/90 原始即单调，不受影响。

> **口径提醒**：头条数字（如 MOEX 期 67.4%）来自 2022-06 起有 MOEX 数据的子集；全样本超额在 7/90 日约 +6 个百分点，30/60 日仅 +1~3 个百分点（边际水平，见下"诚实边界"）。真实、可复现，但别只记大数字。
> **零信号日**：当 |z|<0.3（今日即如此）时模型没有方向证据，置信度数字只是该信号源的历史基础胜率。`forecast_*.json` 带 `weak_signal` 字段可供程序判断；界面展示维持常规涨跌样式。

**核心信号**：`dev = log(MOEX市场价) − log(CBR官方价)`。市场价高于官方 → 官方价未来上追 → CNY/RUB 上涨。这是结构性套利偏离，非过拟合，短窗（1–7 日）最强符合机理。滚动标准化 zdev + 多重同向确认闸门（MOEX 动量 / 偏离加深 / 高波动 / 连续偏离 / 油价 / 新闻情绪）联合分档置信度，动态校准写回 `calibration.json`（48h 有效，过期回退默认）。

无 MOEX 数据的历史日期退回 `MeanRevDirectionPredictor`（线性合成均值回复）。

## 长周期方向预测（30/60/90 日 · 70% 硬门槛模型）

长周期**不再追趋势**（实测趋势跟踪 30 日 49%、90 日 45%，是反指），改用**长期均值回复**：`rev = -(log价 − MA120)/60日波动率`，价格偏离中枢极端 → 预测回归；有 MOEX 数据时要求市场价 z 同向确认。模块 `app/models/longhorizon.py`，纯函数、无状态文件、向量化。

**硬规则（用户约束）**：t 时刻某方向强度桶的扩展窗已实现命中率 **≥70% 且桶内 n≥20** 才输出方向；否则输出**中性（方向不明，只给对称波动区间做预算）**。校准文件缺失/过期（>7 天）时全部安全降级为中性，绝不硬编码置信度。

**每周期发声策略**（预注册候选一次性回测裁决，禁止事后换规则）：30 日经三轮共 15 个候选 + 60 随机参数变体 + 等权合成**无一达 70%**（最好近年代 55.9%；60 变体中 12 个历史过线者尸检 11 个近年代失效）→ 应用户产品决策保留**实验性弱档**（高波动状态下的长期回复，55% 弱门槛，输出永久标注 `experimental`，界面金色虚线"弱倾向·实验中"，投影中位线不偏移，跌破 55% 自动停声，不构成操作依据）；60 日仅"共振"（rev 极端且 MOEX-z 同向）发声；90 日双池。

最新扩展窗 OOS 结果（`data/longhorizon_result.json`，2026-09-12）：

| Horizon | 策略 | 发声规则实测兑现率 | 覆盖率 | 裁决 |
| --- | --- | --- | --- | --- |
| 30 日 | 弱档（实验中） | 全历史 62.4%（n=1012）；**近年代 55.9%** | 54%（高波动日） | ⚠️ 未达 70% → 仅弱倾向展示，永不按"已验证"对待 |
| 60 日 | 共振 only | **73.6%**（n=212，全部 2021 后） | 5% | ✅ 过用户门槛（低覆盖为"少而准"设计属性） |
| 90 日 | 双池 | **71.2%**（n=1304） | 33% | ✅ 通过（分时代 72.6%/64.7%/75.6%） |

**把握度口径（校准）**：卡片展示的把握度 = **发声规则自身的历史实测兑现率**（如 60 日 74%），而非该形态桶的桶命中率——后者存在选择效应虚高（校准检验：60 日桶宣称均值 81.7% vs 实际 63.6%；90 日 84.1% vs 71.2%），桶率仅作详情披露。60 日共振规则的证据全部来自 2021 年后单一市场环境（n=212），95% 置信下界约 68%；滚动校准每日复核，实测跌破 70% 自动转为中性。

### 数据刷新机制

- **快层**（每 60 秒）：拉取 5 个数据源 + 重算预测（~3 秒）
- **慢层**（每天 09:00 MSK）：完整回测 + 校准 + 预测（~8 秒）
- **serve 启动时**：完整同步 + 回测 + 校准 + 预测

## 快速开始

> 环境要求：**Python 3.10+**。安装时**必须勾选 `Add python.exe to PATH`**（安装器默认不勾，漏了会找不到 Python），装完**重开一次终端**。

**方式一（推荐，双击即可）**

1. 双击 `scripts\setup.bat` —— 建 `.venv`、装依赖、下载 ECharts（仅首次）
2. 双击 `start.bat` —— 启动仪表盘

**方式二（命令行）**

```powershell
.\scripts\setup.ps1    # 建 .venv、装依赖、下载 ECharts（仅首次）
.\scripts\run.ps1      # 启动仪表盘（自动同步→回测→校准→预测→双层调度）
```

> `.ps1` **双击不会执行**（Windows 默认用记事本打开）。命令行方式需先打开 PowerShell 并切到项目目录，或在文件管理器里右键 `setup.ps1` → 使用 PowerShell 运行。若提示"禁止运行脚本"，改用 `powershell -ExecutionPolicy Bypass -File .\scripts\setup.ps1`。

> 首次启动需联网抓取历史数据（CBR 自 2010 年）并跑一遍回测；若网络不可用，看板仍会启动，只是暂时没有数据。

**macOS / Linux（Mac 发行包）**

1. 解压后在终端执行 `bash scripts/setup.sh`（建 `.venv`、装依赖、下 ECharts，仅首次；桌宠需 tkinter，Homebrew Python 缺包时按提示 `brew install python-tk`）
2. 双击 `start.command`，或终端执行 `./start.sh` 启动；`./stop.sh` 停止
3. 若双击提示“无法验证开发者”，终端执行一次：`xattr -dr com.apple.quarantine "$(pwd)"`
4. 注意 `.sh` 不能直接双击（会被文本编辑器打开），请双击 `start.command` 或用终端运行

分步执行（venv 的 python）：

```powershell
.\.venv\Scripts\python.exe -m app.cli fetch      # 增量抓取：CBR / Brent / 新闻 / 利率
.\.venv\Scripts\python.exe -m app.cli backtest   # 方向 walk-forward 回测（约 3s）→ direction_result.json
.\.venv\Scripts\python.exe -m app.cli calibrate  # MOEX z 分档置信度校准 → calibration.json
.\.venv\Scripts\python.exe -m app.cli forecast   # 生成当前 7/30/60/90 日预测 → forecast_*.json
.\.venv\Scripts\python.exe -m app.cli serve      # 启动仪表盘（自动全链路 + 双层调度）
```

> `serve` 启动时同步全部数据源 + 回测 + 校准 + 预测。之后快层每 60 秒拉数据+刷新预测，慢层每天 09:00 MSK 重跑回测。

单元测试：`.\.venv\Scripts\python.exe -m unittest discover -s tests -v`（项目根目录）。

## 页面内容

- KPI 卡：当前汇率与日涨跌、方向命中率、信号来源、数据截止日。
- 主图：历史实线 + 未来预测（方向投影 + 喇叭口不确定性带）。不确定性带半宽 = 近 60 日已实现日波动率 ×√k（**1σ 历史波动示意带，非概率置信区间**）；中位线幅度只表达方向，不代表幅度预测。
- 方向表：全样本 / MOEX 期 / MOEX 高置信 命中率。
- 健康卡：MOEX 信号滚动命中率监控。
- 不确定性说明：展开显示预测依据和风险提示。

前端实际调用端点：`/api/predict`、`/api/signal_health`。其余端点已实现但未被当前前端使用（备用/调试）。

## 桌面桌宠

浮在桌面上的小卡片，直接把当前预测显示在眼前，不用一直开着浏览器。

**启动 / 停止**

- `start.bat` — 后台静默起 Flask + 桌宠（**不弹浏览器**）；若服务已在跑则只起桌宠
- `stop.bat` — 同时停掉 Flask 与桌宠
- 也可用 `.\.venv\Scripts\python.exe -m app.cli widget` 单独起桌宠

**卡片**

- 左：角色面板（形态一「儿子」/ 形态二「奶龙」）
- 右上四个圆钮：**地球**（切换形态时是否自动开浏览器，可关）/ **静音** / **最小化** / **关闭**（关桌宠并顺带停掉 Flask）
- 中：方向 + 把握度（底色按涨跌染色）、当前汇率、数据截止日
- 下：`7日 / 30日 / 60日 / 90日` 档位切换，数据联动

**交互**

- 拖动卡片移动；关闭后重开会**回到上次的位置和档位**
- 点左侧角色区 = 切换形态（儿子 ↔ 奶龙）+ 播语音；若「地球」开关开着，同时打开仪表盘网页
- 最小化后变成悬浮球，球上的点按涨跌着色；点球恢复卡片，拖球移动卡片

**配置** `data/pet_config.json`（删掉即回落默认：自动开浏览器=开、档位=7日、位置=右下角）：

```json
{ "auto_browser": true, "horizon": 7, "pos_x": 1180, "pos_y": 620 }
```

**两个坑**

- 语音只认**真 RIFF WAV**。把 `m4a` 直接改后缀成 `.wav` 会**静默失败**（播放无任何报错），必须用播放器"另存为 WAV"真正转码。文件放 `data/pet/voice1.wav`（形态一）/ `voice2.wav`（形态二）。
- 桌宠必须用 `python.exe` 起，**不能用 `pythonw.exe`**（后者不显示 tkinter 窗口）。`launch_widget.vbs` 已按此配置。

## 已知近似与口径说明

- **"交易日"**：回测历史窗口直接用 CBR 实际有牌价的日期序列，不推算；仅「当前预测」的未来日期标签需外推（周末 + 俄法定固定假日：1/1–1/8、2/23、3/8、5/1、5/9、6/12、11/4），调休不建模，个别日期可能偏差 1–2 天。
- 极个别 CBR 缺失交易日做前值填充并记日志（`carry_forward_days`）。
- 回测参数（见 `app/config.py`）：`MIN_TRAIN=300`（窗口起点前至少需要的历史行数）。

## 诚实边界

- 7 日方向预测超越随机是**微弱但真实**的：MOEX 期命中率 67.4%（超额基线 +6~10 点），样本外高置信档 70.0%，覆盖率约 13%。30/60/90 日已改用 70% 硬门槛的长周期回复模型，不达标即显示"方向不明"——长期尺度大部分日子没有可靠方向，这是结论而非缺陷。
- 新闻情绪特征覆盖率低（约 5% 交易日有数据），贡献有限但非零。
- **准确率天花板已确认**：5 轮独立验证（参数调优 / XGBoost / 每日信号 / 信号组合 / 系统审计）确认 56-68% 为当前数据源下的真实上限（全样本口径）；强信号子集可达 70%+ 但窗口稀少，不代表日常表现。
- **不构成投资建议。**
